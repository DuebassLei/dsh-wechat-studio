# 林月半子分享卡片横幅 · 羊毛毡手作(felt)提示词模板

视觉定义:**米色手工纸底 + 羊毛毡/黏土微缩场景 + 宋体特粗中文大标题 + 品牌色小字**。像一张在手工纸上拍摄的羊毛毡立体微缩场景宏观照片:温暖、安静、有手作感。和其他风格最大的区别:标题用**衬线宋体**而不是黑体,右侧是**手作毛毡物件**而不是真人摄影,大多数画面**没有人物**。

每次生成时,把 `{{中括号}}` 占位符换成从文章提炼的新内容,**其他保持不动**。

## 填空指引

### 主标题(2 行)——每篇必改

从文章金句/核心结论里挑,拆两行,**每行 2-8 字**,第一行讲前提,第二行讲反差或结论,高亮词放第二行。这个风格的标题可以很短,短就是力量。

| 第一行(前提)| 第二行(冲击,末尾高亮)|
|---|---|
| API | 向**所有人**开放 |
| 取消 | **5 小时**限制 |
| 每月送 | **API 额度** |
| 能识别 | 也能**检查** |
| 会用 | **电脑**了 |

高亮词用强调色,其余纯黑。标题里不要出现营销腔,优先用文章原句。

### 品牌色 preset——每篇必选

强调色跟随文章主角的品牌色,不要临时发明颜色:

| 品牌 | 强调色 |
|---|---|
| Anthropic / Claude | 赭橙 #D97757 |
| OpenAI / ChatGPT | 深青绿 #10A37F |
| 微信 / 小程序 | 微信绿 #07C160 |
| 百度 / 文心 | 文心蓝 #2932E1 |
| 小米 | 小米橙 #FF6900 |
| 腾讯 / 混元 | 腾讯蓝 #0052D9 |
| 美团 / LongCat | 黑 #111111(品牌绿 #3D9B4F 只放物件细节)|
| 没有明确品牌 / 个人观点 | 赭橙 #D97757(默认)|

对比度规则:品牌色在米色纸上必须可读。太浅的颜色(黄、浅绿)把品牌名和高亮词改成黑色,该颜色只放物件细节。

### 毛毡场景——每篇必改

物件必须是**具体可视化的东西**,从文章主题出发,参考这些对象家族:

| 文章主题 | 对象家族 |
|---|---|
| 时间 / 倒计时 / 限制取消 | 羊毛毡沙漏,沙色用强调色,旁边可挂小吊牌 |
| 电脑使用 / Agent 操作 | 复古羊毛毡 CRT 显示器 + 鼠标,屏幕用色块网格示意 |
| 手机 / 支付 / 小程序 | 羊毛毡手机,屏幕上一个大号价格和按钮色块 |
| 代码 / 终端 / API | 羊毛毡深色终端窗口卡,几行色块代码线 + 一行大号可读命令 |
| 文档 / OCR / 检查 | 黏土纸张文件 + 红色铅笔,纸上有对勾和圈注 |
| 成长 / 上市 / 里程碑 | 黏土摊开的书 + 从书页长出的强调色阶梯 |
| 速度 / 轻量 / Flash | 羊毛毡小鸟骑自行车,身后强调色闪电装饰 |
| 触觉 / 机器人 / 硬件 | 黏土机械手轻触纸面,指尖荡开同心圆涟漪 |
| 品牌 / 开源发布 | 羊毛毡品牌 logo 造型(猫头、鸟等)+ 丝带底座 |
| 个人 Agent / 陪伴 | 羊毛毡小机器人提灯 + 复古设备小物件 |

写场景时给每个物件指明材质(羊毛毡或黏土)、主色和摆放关系,1-3 个物件就够,不要堆满。

### 人物段——二选一,默认无人物

这个风格大多数画面只有物件。文章是人物故事、个人观点或想强化 IP 时填「玩偶」，其余填「无人物」。具体段落由宿主展开。

本风格不使用真人参考图,玩偶的形象和服装来自用户设置。

## 风格基线——不能改的部分

1. 米色手工纸底 `#EFE8D8`,明亮温暖,**禁止深色底**
2. 物件必须是羊毛毡/黏土手作质感,**禁止真实物件摄影、光滑 3D 渲染、塑料玩具感**
3. 主标题**特粗宋体/衬线体**,这是和其他风格最大的区别,禁止黑体
4. 强调色跟随品牌色,只出现在品牌名、高亮词、物件细节三处
5. 文字平面印刷质感,**禁止毛毡化文字、立体字**
6. 人物默认缺席;出现时必须是毛毡玩偶(形象和服装来自用户设置),禁止真人
7. 无水印、无作者署名,画面只有品牌名和标题

## 自检三问

1. **远看是不是"米色纸 + 黑宋体 + 一个低饱和强调色"?** 出现深色底、荧光色或第四种颜色 → 重写
2. **右侧物件像不像手工毛毡/黏土?** 像塑料玩具或真实物件 → 加材质锚点(绒毛纤维、哑光手捏痕)重写
3. **标题是不是衬线宋体?** 渲染成黑体 → 重写
